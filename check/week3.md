# Python 第 8 章验收（函数）

- 定义函数用 def，函数名后面跟括号和冒号，函数体要缩进。调用时写函数名加括号即可。

- 三种传参方式：位置实参按顺序一一对应；关键字实参写成 名字=值，顺序可以打乱；给形参写了默认值后，调用时可以省略该实参。默认值必须放在参数列表的最后。

- return 可以一次返回多个值，写法是 return min(nums), max(nums)。看着像返回两样东西，其实是 Python 把逗号分隔的值自动打包成了一个元组（tuple）。元组用圆括号、不能修改；列表用方括号、可以增删改，别搞混。

- 把列表传给函数，函数里修改它，函数外的列表也会变，因为传过去的是同一个列表对象。

- 想让函数不碰原列表，可以传副本：func(nums[:])。

- 不确定要传几个实参时，形参写 *args，函数会把所有位置实参打包成一个元组。不定数量的关键字实参用 **kwargs。

- 把函数放进单独的 .py 文件就成了模块。导入有三种写法：import tools 是导入整个模块，用 tools.函数名() 调用，能避免命名冲突；from tools import 函数名 是只导入指定函数，可直接调用、代码简洁，但可能和别的名字撞车；import tools as t 是给模块起别名，模块名长或者要防冲突时用。导入模块时写模块名，不带 .py。
