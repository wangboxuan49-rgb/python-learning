## 练习记录

### 词频统计脚本(`ch10/word_report.py`)

读入一个文本文件,输出:总行数、非空行数、总单词数、出现次数最多的 3 个单词。
统计不区分大小写,词频相同时按字母序排列,结果写入 `report.txt`。

实现要点:
- `read_text()` 读全文,`splitlines()` 按行切分,`split()` 按空白切词
- 用两个平行列表存放单词与次数,或用一个字典累加
- 排序采用"次数取负"的元组比较,让降序与字母序一次满足
- `write_text()` 只接受字符串,报表内容自行拼接
- 文件不存在时捕获 `FileNotFoundError` 并友好提示

待补:空文件提示、纯标点 token 过滤。
